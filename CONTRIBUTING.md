# Contributing

Contributions improving Vietnamese wording, terminology, compatibility, tests, or documentation are welcome.

## Translation rules

- Prefer clear, natural Vietnamese used in software interfaces.
- Preserve placeholders such as `{name}`, `{count}`, `{path}`, and `{error}` exactly.
- Keep product names and technical tokens when translating them would reduce clarity.
- Do not translate user/model/provider content; this repository translates product-authored UI copy.
- Run `npm test` and `npm run verify` before submitting changes.

For wording changes, include the namespace, key, current text, proposed text, and a short reason.
